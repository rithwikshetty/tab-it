Production firewall

Nothing silently points at live Supabase

  • No reset, recreate, truncate, drop, reseed or bulk-delete workflow.
  • Development uses mocks, local Supabase or an explicitly isolated non-production environment.
  • Future schema work must be forward-only, compatible with existing users, tested away from production and separately approved.
  • Production credentials never become a debug fallback and service-role keys never ship in either app.
